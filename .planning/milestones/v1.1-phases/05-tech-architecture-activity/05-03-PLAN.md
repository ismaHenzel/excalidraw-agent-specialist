      `textAlign`, `verticalAlign`, `originalText`. Use one standalone `text` per action label / decision
      label / lane title / arrow label — never a single multi-line block, never a `label` prop on a shape.
    - text_overflow_static: size each action rectangle wide enough for its label (`len(text)*0.6*fontSize`),
      or shorten labels.
    - image_path_unresolvable: Activity nodes need no icons — omit `image` elements (if a lane brand icon
      is used, point `file_path` at an existing `icons/*.png`).

    `elbowed: true`, `roundness: null`, ≥3 orthogonal points on every arrow; `roughness: 0`;
    `fontFamily: 3` on all text. Use the same top-level JSON envelope as process_decision.excalidraw
    (`type`, `version`, `source`, `elements`, `appState`, `files`).

    Then run the validator + structural verifier and iterate until both are clean:
    `python3 scripts/render/excalidraw_validator.py examples_excalidraw/activity_order_fulfillment.excalidraw`
